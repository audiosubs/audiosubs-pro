Política de Privacidade

Última atualização: 02/08/2026

1. O processamento é local

O AudioSubs processa áudio, transcrição e tradução inteiramente no seu computador. Nenhum vídeo, áudio ou texto transcrito é enviado aos nossos servidores.

2. O que é armazenado no seu PC

O app guarda apenas configurações locais: preferências de idioma, seu status de licença (grátis/trial/PRO) e contadores de uso diário. Essas informações ficam no seu disco, em %APPDATA%\audiosubs\config.json e no Registro do Windows.

3. O que é enviado para a internet

  • Quando você usa uma URL: o app baixa o vídeo/áudio público daquela URL (mesma ação de abrir o link em um navegador).
  • Modelo de IA: na primeira transcrição, o app baixa o modelo Whisper (~220 MB) de um servidor de modelos (Hugging Face).
  • Tradução: a tradução usa um endpoint público de tradução. Se quiser 100% offline, mantenha o idioma "original".
  • Ativação da licença: a chave PRO é validada localmente; nenhuma informação pessoal é enviada para ativar.

4. Dados de compra

Compras são processadas por plataformas terceiras (Gumroad para pagamentos internacionais e Hotmart para o Brasil). A AudioSubs recebe apenas o e-mail do comprador para emitir a chave de licença. Não temos acesso a dados de cartão.

5. Dados não coletados

Não coletamos telemetria, uso anônimo, histórico de URLs, conteúdo transcrito nem dados biométricos. Sem contas, sem cadastro para usar o app.

6. Direitos e contato

Para qualquer dúvida sobre privacidade ou para solicitar exclusão de dados de compra, escreva para SEU_EMAIL@exemplo.com.
